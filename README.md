# Employee Attrition and Workforce Analytics

## Project Overview

This project explores how data analytics can help organisations understand employee attrition, workforce composition, and employee retention.

Using a synthetic employee dataset, the project will demonstrate how SQL, Python, and Power BI can support evidence-based HR decisions and workforce planning.

**Project status:** In progress

## Business Problem

Employee turnover can create recruitment costs, operational disruption, and the loss of organisational knowledge.

The objective of this project is to analyse workforce data, identify patterns associated with employee attrition, and develop practical recommendations for improving retention.

## Project Objectives

- Analyse employee headcount and workforce composition.
- Calculate employee attrition rates.
- Compare attrition across departments and job roles.
- Explore relationships between tenure, compensation, job satisfaction, and attrition.
- Develop workforce KPIs and visualisations.
- Present evidence-based recommendations to management.

## Tools and Technologies

- SQL — data querying and KPI calculations.
- Python — data preparation and exploratory analysis.
- pandas — data manipulation.
- Power BI — interactive dashboard development.
- Git and GitHub — version control and project documentation.

## Key Business Questions

1. What proportion of employees leave the organisation?
2. Which departments experience the highest attrition?
3. How does attrition vary with employee tenure?
4. Are there differences in attrition across job levels?
5. Which workforce indicators should management monitor?
